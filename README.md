# ETF网格交易策略系统

基于XtQuant的ETF自动化网格交易策略，支持实盘、模拟交易和历史回测。

## 功能特性

### 核心功能
- ✅ **XtQuant连接**: 连接国金证券QMT交易系统获取实时行情数据
- ✅ **网格交易策略**: 基于Table.xls配置的ETF网格交易策略
- ✅ **历史数据回测**: 完整的历史数据回测功能和性能分析
- ✅ **自动化下单**: 基于XtQuant的自动化订单执行
- ✅ **风险管理**: 全面的风险控制和监控功能

### 支持的ETF（从Table.xls解析）

- 159380 - A500指数

- 159937 - 平安9999
- 513730 - 通信ETF
- 513130 - 纳斯达克

## 配置说明

### 1. QMT数据路径配置
在 `config/settings.py` 中设置QMT数据路径：
```python
QMT_DATA_DIR = r"C:\Users\zhanghang\国金证券QMT交易端\datadir"
```

### 2. Table.xls配置
Table.xls包含ETF网格交易配置，格式如下：
- ETF代码
- ETF名称
- 基准价格
- 上涨触发比例
- 下跌触发比例
- 买入金额
- 卖出金额
- 有效期

### 3. 风险参数配置
在 `config/settings.py` 中配置风险参数：
```python
class RiskManagementConfig:
    max_daily_loss = 0.05        # 单日最大亏损5%
    max_single_order_ratio = 0.1 # 单笔订单最大10%
    max_total_position = 0.8     # 最大总仓位80%
    stop_loss_ratio = 0.15       # 止损15%
    take_profit_ratio = 0.20     # 止盈20%
```

## 使用说明

### 1. 运行主程序
```bash
python main.py
```

### 2. 选择运行模式
```
ETF网格交易策略系统
========================================
1. 实盘交易
2. 模拟交易
3. 运行回测
4. 退出
========================================
```

### 3. 实盘交易
- 选择 "1" 启动实盘交易
- 系统会连接QMT并开始自动交易
- 按 Ctrl+C 停止系统

### 4. 模拟交易
- 选择 "2" 启动模拟交易
- 系统会模拟交易但不产生实际订单
- 适合策略测试和验证

### 5. 历史回测
- 选择 "3" 运行历史回测
- 系统会基于历史数据测试策略表现
- 生成详细的回测报告

## 策略原理

### 网格交易策略
网格交易是一种量化交易策略，通过在价格区间内设置买入和卖出网格来实现自动化交易：

1. **买入网格**: 价格下跌到预设水平时自动买入
2. **卖出网格**: 上涨到预设水平时自动卖出
3. **动态调整**: 根据市场情况动态调整网格中心
4. **风险控制**: 严格控制仓位和单日损失

### ETF配置示例
以159682半导体ETF为例：
- 基准价格：1.408元
- 上涨触发：每5%卖出一次
- 下跌触发：每5%买入一次
- 每次买入：20000元
- 每次卖出：20000元

## 风险管理

### 内置风险控制
- **仓位限制**: 单个ETF最大30%，总仓位最大80%
- **日损失限制**: 单日最大亏损5%
- **订单大小限制**: 单笔订单最大10%
- **回撤控制**: 最大回撤超过20%自动停止
- **集中度控制**: 避免过度集中风险

### 实时监控
- 持仓实时监控
- 盈亏实时计算
- 风险告警系统
- 紧急停止机制

## 注意事项

### 使用前必读
1. **充分测试**: 建议先用模拟交易测试策略
2. **风险认知**: 网格交易不保证盈利，存在亏损风险
3. **资金管理**: 建议使用闲置资金进行交易
4. **监控重要**: 需要定期监控系统运行状态

### 常见问题
1. **QMT连接失败**: 检查QMT是否正常运行，数据路径是否正确
2. **订单执行失败**: 检查账户资金是否充足，网络连接是否正常
3. **策略异常**: 查看日志文件定位具体问题

### 技术支持
如遇到技术问题，请：
1. 查看日志文件定位问题
2. 检查QMT连接状态
3. 验证配置参数是否正确
